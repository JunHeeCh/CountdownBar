## 왜 CountdownBar인가?

발표, 마감, 시험, 수강신청, 한정 판매.
중요한 순간은 언제나 갑자기 다가옵니다.

CountdownBar은 **macOS 메뉴바에 항상 남은 시간을 표시**합니다.
다른 창을 열거나 앱을 전환할 필요 없이, 눈 한 번 올리면 바로 확인.

시간이 촉박해질수록 아이콘은 더 빠르게 움직이고, 색상은 빨갛게 변합니다.
몸이 먼저 긴장하게 만드는 카운트다운입니다.

---

## 기능 소개

### ⏱ 항상 보이는 카운트다운
메뉴바에 실시간으로 남은 시간을 표시합니다. 다른 작업을 하는 중에도 시간을 놓치지 않습니다.

두 가지 표시 방식을 지원합니다:
- **D-day 모드** — `D-3 14:22:05` 형태로 날짜와 시간을 함께 표시
- **시:분:초 모드** — `86:22:05` 형태로 총 남은 시간만 표시

### 🎨 긴박감을 알려주는 색상 변화
남은 시간에 따라 메뉴바 텍스트 색상이 자동으로 바뀝니다.

| 상태 | 색상 |
|------|------|
| 여유 있음 | 기본색 |
| 주의 (기본 60분 이내) | 🟠 주황 |
| 위험 (기본 5분 이내) | 🔴 빨강 |
| 종료 | ⚫ 회색 |

빨강/주황 기준 시간은 슬라이더로 직접 조절할 수 있습니다.

### 🐾 아이콘 애니메이션 & 커스텀
기본 제공 이미지가 남은 시간에 맞춰 속도를 바꾸며 움직입니다.

- 여유로울 땐 느긋하게
- 마감이 다가올수록 점점 빠르게
- 종료되면 멈춤

**원하는 이미지로 교체 가능합니다.** 설정 패널에서 "애니메이션 이미지 등록" 버튼을 누르고 PNG, JPG 등 이미지를 여러 장 선택하면 자동으로 애니메이션됩니다. 등록한 이미지는 앱을 재시작해도 유지됩니다.

### 📝 메모
어떤 카운트다운인지 메모를 남길 수 있습니다. 설정 패널 상단 메모 영역을 클릭해 입력하면, 메뉴바 아이콘에 마우스를 올렸을 때 툴팁으로 표시됩니다. (최대 20자)

### 🌐 서버 시간 기준 카운트다운
내 컴퓨터 시계가 느리면 어쩌죠? CountdownBar은 선택적으로 **특정 서버의 시간을 기준**으로 카운트다운할 수 있습니다.

URL을 입력하고 동기화하면, 이후엔 인터넷 연결 없이도 서버 기준 시간으로 정확하게 작동합니다. 수강신청, 한정 판매처럼 서버 시간이 중요한 상황에서 유용합니다.

## 다운로드

**[⬇ 최신 버전 다운로드](https://github.com/JunHeeCh/CountdownBar/releases/latest)**

1. 위 링크에서 `CountdownBar.zip`을 다운로드합니다.
2. 압축을 풀고 `CountdownBar.app`을 **응용 프로그램** 폴더로 이동합니다.
3. **처음 실행 시:** Gatekeeper 경고가 뜨면 앱 아이콘을 **우클릭 → 열기**를 선택하세요.
   > Apple 공증을 거치지 않은 앱이라 최초 1회만 이 과정이 필요합니다.

---

## 사용 방법

1. 앱을 실행하면 메뉴바 오른쪽에 카운트다운이 표시됩니다.
2. 메뉴바 아이템을 클릭하면 설정 패널이 열립니다.
3. 목표 시각을 입력합니다. (년/월/일, 24시간제)
4. 표시 방식과 색상 기준을 취향에 맞게 조절합니다.
5. 패널 바깥을 클릭하면 닫힙니다.

## 직접 빌드하기

소스에서 직접 빌드하고 싶다면:

1. 저장소를 클론합니다.
   ```bash
   git clone https://github.com/JunHeeCh/CountdownBar.git
   ```
2. `CountdownBar.xcodeproj`를 Xcode로 엽니다.
3. **Signing & Capabilities**에서 개발자 계정을 연결합니다.
4. `⌘R`로 빌드 및 실행합니다.
